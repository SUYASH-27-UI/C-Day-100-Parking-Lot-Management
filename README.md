# C Day 100 – Parking Lot Management System

## Description
A menu-driven parking management application developed using C structures, dynamic memory allocation, and file handling.

## Features
- Park vehicles in available slots.
- Display parked vehicles.
- Search vehicles by registration number.
- Remove vehicles from parking slots.
- Track available and occupied slots.
- Store parking information permanently.

## Files
- `parking.c` – Main C program.
- `parking.txt` – Sample parking records.

## How to Compile
```bash
gcc parking.c -o parking
```

## How to Run
Windows:
```bash
parking.exe
```

Linux:
```bash
./parking
```

## Concepts Used
- Structures
- Pointers
- Dynamic Memory Allocation
- malloc() and free()
- File Handling
- String Functions
- Array Operations

## Note
This project uses a maximum capacity of 50 parking slots and is an educational simulation.
